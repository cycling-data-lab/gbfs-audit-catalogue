# Unified A1-A7 audit (one pipeline, France + world)

Reproducible "archive then audit": `gbfs_toolkit.audit_static` applied
identically to the certified French catalogue and to a live re-fetch of the
MobilityData world catalogue (France included), so the FR and World columns are
finally comparable under a single rule set.

Run from `../../notebooks/`:

    python run_unified_audit.py             # full live sweep (resumable) -> regenerates the lake
    python run_unified_audit.py --audit-only   # deterministic audit from the frozen lake

## Tracked here (the results)
- `RESULTS.json`          headline metadata: seed, params, toolkit version, FR + World A1-A7 (feed-only and operator variants)
- `unified_summary.csv`   per-class system counts + cluster-bootstrap 95% CIs (seed 42)
- `world_fetch_manifest.csv`  per-system provenance: UTC timestamp, SHA-256, station count, status
- `MANIFEST.json`         cryptographic manifest of the raw lake

## Not tracked (regenerable, git-ignored)
- `raw_world/`            frozen station_information per system (~14 MB; archive on Zenodo if cited)
- `unified_verdict.parquet`  station-level A1-A7 verdict (regenerated by `--audit-only`)
